# My-Projects

This repository contains an archive of my early learning projects and experimental work in zero-knowledge proofs (ZKP), Circom, and circuit security.

These projects were developed during my initial exploration of zero-knowledge proof systems and related security topics. Some experiments may have been superseded by later, independently maintained repositories.

## Projects

| Directory | Description |
|---|---|
| `Under-Constrained/` | Experiments on under-constrained circuit vulnerabilities and circuit security analysis. |
| `first-circom/` | Early Circom circuit development and constraint experiments. |
| `privacy-balance-zk/` | An early privacy-preserving balance proof experiment. |
| `test/` | Small Circom circuit and witness testing examples. |
| `zkp-ai-security/` | Exploratory experiments combining ZKP and AI security concepts. |
| `zkp-security-lab/` | Circuit security analysis, mutation experiments, and detection reports. |

## Repository Status

This repository is retained as a historical learning and experimentation archive.

- Existing source code, experiment records, and reports are preserved.
- Some projects may overlap conceptually with later independent repositories.
- The experiments are not necessarily maintained or guaranteed to work with current toolchain versions.
- No claim is made that every experiment is production-ready or independently security-audited.

For current research and actively maintained projects, please refer to the corresponding standalone repositories on my GitHub profile.

## Notice

This repository is archived for historical reference. It is not intended to serve as the primary development location for ongoing research.
